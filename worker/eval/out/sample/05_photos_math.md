# Kvadratická rovnice: diskriminant a parabola

Hodina o řešení kvadratické rovnice pomocí diskriminantu a o souvislosti s grafem funkce, parabolou. Na příkladu 2x² − 5x + 3 = 0 se ukázalo určení koeficientů, výpočet D, dosazení do vzorce a zkouška. Diskriminant se podle učitele na písemce ptá vždycky. Domácí úkol: pracovní sešit, strana 31, příklady 12 a 14, odevzdat příští středu.

## Osnova
### Obecný tvar a určení koeficientů
- Obecný tvar kvadratické rovnice: ax² + bx + c = 0; a, b, c jsou čísla (koeficienty)
- Podmínka a ≠ 0: kdyby a = 0, není tam x² a je to lineární rovnice (na tu se rádo zapomíná)
- Určení koeficientů: a je číslo před x², b je číslo u x, c je osamocené číslo na konci
  - Pozor na znaménka: minus patří k číslu za ním (nejčastější chyba), minus si vezmeš s sebou
  - Příklad: 2x² − 5x + 3 = 0 → a = 2, b = −5, c = 3
- Rovnice zapsaná v jiném pořadí: nejdřív ji převést na základní tvar (všechno na jednu stranu, vpravo nula, seřadit podle mocnin), teprve pak číst a, b, c
### Diskriminant a počet řešení
- Diskriminant: D = b² − 4ac (b² minus čtyři krát a krát c)
- Pozor: b² je kladné i při záporném b (minus krát minus je plus); na písemkách se to chybuje často
- Tři případy podle D
  - D > 0: dva různé reálné kořeny
  - D = 0: jeden, takzvaný dvojnásobný kořen
  - D < 0: žádný reálný kořen; neznamená to, že řešení je nula, nula je jiné řešení než žádné řešení
- Proč to tak je: ve vzorci je √D
  - Z a záporného čísla nejde v reálných číslech odmocnina → D < 0 žádný reálný kořen
  - D = 0: √0 = 0, takže −b + 0 a −b − 0 jsou totéž → jeden kořen
### Vzorec pro kořeny
- x₁,₂ = (−b ± √D) / (2a)
- Ve jmenovateli je 2a, ne 2ac
- Zlomková čára je přes celý čitatel: dělí se jak −b, tak odmocnina (nejen odmocnina)
- Jednou se dosadí plus, podruhé mínus → x₁ a x₂
### Příklad: 2x² − 5x + 3 = 0
- a = 2, b = −5, c = 3
- D = b² − 4ac = 25 − 24 = 1 → D > 0, čekají se dva různé kořeny
- x₁,₂ = (5 ± 1) / 4
- x₁ = 3/2, x₂ = 1
- Zkouška: dosadit každý kořen zpět do původní rovnice, musí vyjít nula (učitel ji doporučuje dělat vždycky)
### Graf: parabola a počet kořenů
- Řešení rovnice ax² + bx + c = 0 odpovídá průsečíkům grafu funkce y = ax² + bx + c s osou x
- Grafem je parabola; a > 0: otevřená nahoru (úsměv), a < 0: otevřená dolů (smutný obličej)
- Vrchol: bod, kde se parabola otáčí (u a > 0 nejnižší bod)
- Souvislost s D (nakreslit si všechny tři případy)
  - D > 0: parabola protíná osu x ve dvou bodech (kořeny)
  - D = 0: parabola se osy x jen dotkne vrcholem
  - D < 0: parabola leží nad osou x a osu neprotne (případ a > 0)
- V příkladu y = 2x² − 5x + 3 jsou průsečíky s osou x v bodech 1 a 3/2; vrchol V leží mezi nimi
- Vrchol leží uprostřed mezi kořeny, na ose symetrie; x-ová souřadnice vrcholu = −b / (2a), což je první část vzorce před odmocninou
- Odmocnina určuje, jak daleko od středu jsou kořeny na obě strany
### Další poznámky k počítání
- Když D vyjde s odmocninou: nechat s odmocninou, nebo zaokrouhlit podle zadání; když zadání nic neříká, nechat přesný tvar
- Kalkulačka je povolená, ale nespoléhat na ni (neodhalí opsané špatné znaménko)
- Druhá cesta řešení, rozklad na součin a Viètovy vzorce, bude příště; dnes jen diskriminant
- Na konci hodiny se začal počítat další společný příklad začínající 2x² (zadání v přepisu není celé)

## Klíčové body
- [definition] **Kvadratická rovnice**: Rovnice tvaru ax² + bx + c = 0, kde a, b, c jsou koeficienty a a ≠ 0 (jinak by byla lineární).
- [formula] **Diskriminant**: D = b² − 4ac
- [formula] **Kořeny kvadratické rovnice**: x₁,₂ = (−b ± √D) / (2a); zlomková čára je přes celý čitatel, ve jmenovateli je 2a.
- [key] D > 0: dva různé reálné kořeny; D = 0: jeden dvojnásobný kořen; D < 0: žádný reálný kořen.
- [important] Diskriminant se na písemce ptá vždycky, umět ho je nutné.
- [important] Znaménko patří k číslu: b = −5 má b² = 25. Nejčastější chyba je ztracené minus.
- [important] D < 0 neznamená, že řešení je 0. Znamená, že v reálných číslech žádné řešení neexistuje.
- [important] Zkoušku dělat vždycky: dosadit kořeny zpět do původní rovnice, musí vyjít nula.
- [formula] **Souřadnice x vrcholu paraboly**: x_V = −b / (2a); vrchol leží uprostřed mezi kořeny, na ose symetrie.
- [example] 2x² − 5x + 3 = 0: a = 2, b = −5, c = 3; D = 25 − 24 = 1; x₁,₂ = (5 ± 1)/4; x₁ = 3/2, x₂ = 1.
- [key] Parabola y = ax² + bx + c: a > 0 otevřená nahoru, a < 0 otevřená dolů; kořeny rovnice jsou průsečíky s osou x.

## Studijní materiály
- [practice_question] Koeficienty se záporným znaménkem: Urči a, b, c v rovnici −3x² + x − 7 = 0 a vypočítej b².  -> a = −3, b = 1, c = −7 (minus patří k číslu za ním). b² = 1² = 1.
- [practice_question] Rovnice v jiném pořadí: Rovnice je zapsána jako 3 + 2x² = 5x. Jak z ní zjistíš a, b, c?  -> Nejdřív ji převedeme na základní tvar: všechno na jednu stranu, vpravo nula, seřadit podle mocnin: 2x² − 5x + 3 = 0. Pak a = 2, b = −5, c = 3.
- [practice_question] Proč D < 0 nemá reálný kořen: Vysvětli, proč rovnice s D < 0 nemá v reálných číslech řešení a proč při D = 0 vychází jen jeden kořen.  -> Ve vzorci je √D. Ze záporného čísla nejde v reálných číslech odmocnina, proto při D < 0 žádný reálný kořen. Při D = 0 je √0 = 0, takže −b + 0 a −b − 0 dávají totéž číslo, tedy jeden (dvojnásobný) kořen.
- [practice_question] Výpočet D a počet kořenů: Spočítej D pro rovnici x² − 4x + 4 = 0 a rozhodni, kolik má kořenů.  -> a = 1, b = −4, c = 4. D = (−4)² − 4 · 1 · 4 = 16 − 16 = 0. Rovnice má jeden dvojnásobný kořen: x = 4/2 = 2. Parabola se osy x dotýká vrcholem.
- [practice_question] Graf a kořeny: Parabola y = ax² + bx + c leží celá nad osou x. Jaké je D a kolik reálných kořenů má rovnice? Co víme o a?  -> Parabola osu x neprotíná, takže D < 0 a rovnice nemá žádný reálný kořen. Parabola je otevřená nahoru, tedy a > 0.
- [flashcard] Diskriminant: Jaký je vzorec pro diskriminant?  -> D = b² − 4ac
- [flashcard] Vzorec pro kořeny: Jak se spočítají kořeny kvadratické rovnice?  -> x₁,₂ = (−b ± √D) / (2a); zlomková čára je přes celý čitatel.
- [flashcard] Vrchol paraboly: Kde leží vrchol vzhledem ke kořenům a jaká je jeho x-ová souřadnice?  -> Uprostřed mezi kořeny, na ose symetrie; x_V = −b / (2a).
- [topic_to_review] Doplněno: Viètovy vzorce a rozklad na součin: Učitel zmínil, že příště bude druhá cesta řešení, rozklad na součin a Viètovy vzorce. Nastuduj si, jak se kořeny vztahují ke koeficientům, a vyzkoušej to na kořenech 1 a 3/2 z dnešního příkladu.
- [search_terms] Hledání doplňujících materiálů: kvadratická rovnice diskriminant; parabola vrchol a osa symetrie; Viètovy vzorce; quadratic equation discriminant
